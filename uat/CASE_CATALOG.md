# bluedb UAT Case Catalog

The authoritative case catalog is generated by the runner:

```bash
python3 uat/uat_suite.py --list-cases
```

As of the latest verified run, the full profile contains 1,659 cases:

| Family | Cases |
|---|---:|
| Preserved broad black-box workflows | 99 |
| Generated REST table matrix | 100 |
| Generated SQL expression matrix | 560 |
| Generated SQL function matrix | 900 |
| **Total** | **1,659** |

Generated IDs are stable and grouped by feature:

| ID prefix | Feature | Docs |
|---|---|---|
| `UAT-REST-MATRIX-*` | `rest.tables` | `docs/api/rest.md#tables` |
| `UAT-SQL-EXPR-*` | `sql.expressions` | `docs/sql/expressions.md` |
| `UAT-SQL-FUNC-*` | `sql.functions` | `docs/sql/functions.md` |

Generated run reports include feature, priority, profile, and
document-reference coverage for the executed profile. Transient run reports are
written under `uat/reports/`; the checked-in blessed release snapshot is
`uat/reports/blessed/latest-uat-report.md`.
